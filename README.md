#Исследование 1. Что находится внутри int
int number = 1; -> 01-00-00-00
int number = 256; -> 00-01-00-00
int number = 65536; -> 00-00-01-00
1. Число 1 занимает 4 байта, потому что тип данных int передаёт компьютеру фиксированное число байт, чтобы тот понимал, чо перед ним число int. А поскольку число 1 можно записать 1 байтом, остальные байты заполняются 0.
2. В битовом представлении числа 256, по сравнению с 1, изменяется положение 01 внутри представления: для 1 она находится в первом слева байте, а для 256 во втором слева.
3. Число 65536 требует другого набора байтов, потому что 2 байта может занимать максимально число 65535 (исходя из двоичного представления числа), поэтому для кодирования 65536 задействуется ещё и 3 байт.
#Исследование 2. Почему порядок байтов имеет значение
BitConverter.IsLittleEndian -> True
Байты числа: 78-56-34-12

# Лабораторная работа №3
## Цель
Понять, почему значение int занимает несколько байтов; что такое шестнадцатеричное представление байтов; почему порядок байтов может иметь значение; почему один и тот же текст на разных кодировках занимает разное количество байтов; почему компьютер хранит и число, и текст в виде байтов, но программа обращается с ними по-разному.
## 1. Представление числа в байтах
Для выбранных значений:
- 1: 01-00-00-00
- 256: 00-01-00-00
- 65536: 00-00-01-00
Если число в двоичной записи превышает 1, 2 и т.д. байт, берётся ещё один байт и продолжается кодирование.
## 2. Порядок байтов
- значение `BitConverter.IsLittleEndian`: True
- число `305419896`;
- его hex-представление: 0x12345678
- получившиеся байты: 78-56-34-12
- краткое объяснение порядка байтов: В Little-endian сначала записывается младший разряд числа в шестнадцатеричном виде 12-34-56-78
## 3. Текст и UTF-8
- `ABC`: 3 символа и 3 байта.
- `Привет`: 6 символов и 12 байт.
Количество символов и байт может различаться, потому чо UTF-8 кодирует огромное множество символов и использует для их кодирования от 1 до 4 байт.
## 4. Английская и русская буква
- `A`: 41
- `А`: D0-90
В UTF-8 символ А английский и русский находятся в разных разделах кодировки и поэтому представляются по разному.
## 5. Обратное преобразование
Исходная строка: Привет
Восстановленная: Привет
Исходное число: 123456789
Восстановленное: 123456789
## Контрольные вопросы
1. Байт — это базовая единица хранения и обработки цифровой информации, содержит 8 бит.
2. Тип данных int может хранить большие целые числа (как положительных, так и отрицательных). Один байт даёт 256 различных чисел, поэтому, чтобы вместить широкий диапазон чисел типу int требуется 4 байта (32 бита), что дает 2^32 = 4_294_967_296 возможных чисел. 
3. Метод BitConverter.GetBytes() представляет переданноеему значение (число, текст) в виде последовательности байтов, которые как раз обратываются компьютером.
4. BitConverter.IsLittleEndian показывает порядок байтов, которые обрабатывает компьтер. Если его значение равно True (Little-Endian), то байты записи числа записываются начиная с младшего разряда, т.е. запись числа "переворачивается", если значение False, то байты записываются в том же порядке, начиная со старшего. Большинство современных потребительских процессоров (x86, x64, ARM) работают по схеме Little-Endian.
5. Порядок байтов может отличаться от привычной записи числа, потому что процессорам удобнее начинать обработку с младших байтов, так как арифметические операции всегда начинаются с самого младшего разряда, и из-за этого в большинстве компьютеров используется Little-Endian, который сразу передаёт компьютеру уже "перевёрнутую" запись числа, чтобы оптимизировать обработку.
6. Потому что символ строки и байт — это разные значения(символ — это абстрактный знак, а байт — единица памяти), и в зависимости от кодировки один символ может кодироваться несколькими байтами (как например UTF-8 кодирует символы 1-4 байтами).
7. Метод Encoding.UTF8.GetBytes() кодирует текст по кодировке UTF-8 и передаёт эти байты компьютеру.
8. Метод Encoding.UTF8.GetString() выполняет обратную операцию декодирования. Он принимает последовательность байтов, «читает» его по правилам UTF-8, находит границы символов и собирает байты обратно в понятную человеку текстовую строку.
9. Байты в памяти компьютера — это набор нулей и единиц, которые не несут информации о своём типе данных, поэтому компьютер не будет знать, что именно они значат, пока программа не применит к ним конкретный тип данных.
10. Число переводится в память с помощью математических правил, а текст переводится в память через таблицы кодирования.
## Итоговый вывод
В памяти компьютера все данные хранятся в виде байтов, состоящих из нулей и единиц, и физически неотличимы друг от друга. Числа записываются напрямую через двоичную систему счисления, в то время как текст преобразуется в байты с помощью таблиц кодировок, где каждому символу присвоен свой уникальный числовой код. Последовательность байтов не содержит информации о своем типе, компьютеру необходимы строгие правила интерпретации (типы данных).
